# Indexer (Go)

This directory contains the Go semantic-analysis and indexing component for RepoPilot.

## Week 1 Feasibility Spike: `cmd/spike-loader`

`cmd/spike-loader` is a standalone feasibility tool developed for Week 1 Track A evaluation. It uses `golang.org/x/tools/go/packages` to load, type-check, and extract a deterministic inventory of packages, declarations, imports, and interface definitions from a target Go repository.

### CLI Usage

```bash
# Basic usage from indexer-go/
go run ./cmd/spike-loader -repo <path-to-target-repo>

# Or with custom package pattern
go run ./cmd/spike-loader -repo <path-to-target-repo> -pattern ./...
```

### Output and Behavior

- **Standard Output (`stdout`)**: Deterministic JSON report containing package summaries, declaration counts, interface names, coarse source test inventory, and diagnostics.
- **Standard Error (`stderr`)**: Informational and fatal execution error logs.
- **Status Field**:
  - `status: "complete"` (exit code 0): All packages parsed and type-checked cleanly with 0 diagnostics.
  - `status: "partial"` (exit code 1): One or more packages contained parse/type errors or ill-typed packages. Diagnostics are captured in the JSON report.

### Scope Limitations and Non-Goals

- **Not Canonical Evidence Contract**: The JSON output produced by this spike is a local evaluation report, **not** the finalized `EvidenceRef` schema or canonical evidence model.
- **Source Test Inventory**: Counts of test files and test-like functions (`Test...`, `Benchmark...`, `Example...`, `Fuzz...`) represent coarse source-level inventory only and do not indicate executed tests or test pass rates.
- **Excluded Features**: SSA generation, call-graph construction (CHA/RTA/VTA), reference graphs, graph database storage, and incremental indexing are explicitly out of scope for this feasibility spike.

## Week 2 Evidence Exporter: `cmd/evidence-export`

`cmd/evidence-export` is the Week 2 Track A exporter that emits commit-scoped, line-based `evidence.jsonl v0` records for `DECLARES`, `DEFINED_IN`, and `IMPORTS` relations along with fail-closed diagnostics envelopes.

### CLI Usage

```bash
# Basic usage from indexer-go/
go run ./cmd/evidence-export \
  -repo <abs-path-to-target-repo> \
  -repo-id <owner/repo> \
  -commit <full-40-hex-commit-sha> \
  -diag-out <path-to-diagnostics-envelope.json> \
  [-pattern ./...]
```

### Flags

- `-repo` (required): Absolute path to target repository root. Must be inside a clean Git work tree.
- `-repo-id` (required): Canonical repository identifier (e.g. `uber-go/zap`, `stretchr/testify`).
- `-commit` (required): Expected full 40-character commit SHA. The exporter verifies HEAD matches this SHA; mismatch aborts with `status: "failed"` and exit code 2.
- `-diag-out` (required): File path where the diagnostics envelope JSON is written.
- `-pattern` (optional, default `./...`): Go package pattern to analyze.

### Stream Separation & Exit Codes

- **Standard Output (`stdout`)**: `evidence.jsonl` records (single-line JSON objects, sorted byte-lexicographically for determinism).
- **Diagnostics File (`-diag-out`)**: Formatted JSON envelope capturing overall status and diagnostics items.
- **Standard Error (`stderr`)**: Operational errors and log messages.
- **Exit Codes**:
  - `0` (`status: "complete"`): Zero error diagnostics; full extraction completed.
  - `1` (`status: "partial"`): Error diagnostics detected; records emitted for extractable declarations alongside diagnostics envelope.
  - `2` (`status: "failed"`): Fatal precondition failure (dirty git work tree, commit SHA mismatch, invalid path, or top-level `packages.Load` failure).

### Determinism & Extraction Invariants

- **Determinism**: Identical candidate commit + same exporter produces byte-identical JSONL output and diagnostics envelopes across repeat runs.
- **Source Range Bounds**: Every record satisfies `1 <= start_line <= end_line <= totalLines` validated against file bytes on disk.
- **Option-A Artifact Hash**: `artifact_hash` is computed as `sha256:` of raw source file bytes at the verified commit.
- **Excluded Scope**: `_test.go` files are excluded (`Tests: false`); dynamic call graphs, SSA, and historical patch relations are deferred to subsequent phases.
- **Not Canonical 1.0 Schema**: The `0.1-draft` records generated by this exporter are Week 2 implementation inputs for Track B/C review, not finalized `1.0-rc` canonical JSON Schemas.
