# RepoPilot

RepoPilot is an evidence-grounded code-intelligence and patch-evaluation platform for Go repositories.

## Current Status

- **Status**: Feasibility / Week 1
- **Phase**: Phase 1 (Repository Bootstrap)
- **Note**: Full implementation proceeds only after passing repository feasibility Gate G0. This project is currently in early feasibility exploration and is neither production-ready nor making performance claims.

## Component Ownership

- `indexer-go/`: Go program analysis and semantic indexing.
- `contracts/`: Versioned cross-component schemas and data contracts.
- `docs/`: Architecture Decision Records (ADRs) and gate evidence artifacts.
- `fixtures/`: Controlled test and analyzer fixtures for verification.
- `scripts/`: Project automation, builds, and development tooling.
