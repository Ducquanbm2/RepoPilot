# Contracts

This directory will contain versioned, machine-readable contracts and schemas defining cross-component data interfaces across the RepoPilot monorepo.

## Status

- `EvidenceRef` and related contracts are **not finalized** in Phase 1 and will be formally drafted in Phase 3.
- Material schema changes introduced in future phases require explicit review and backward compatibility guarantees across consumers.
- No concrete schema fields are defined at this stage.
